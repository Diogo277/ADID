# GUIA RAPIDO

## Passo 1 - Instalar a extensao

1. Abra chrome://extensions/
2. Ative "Modo do desenvolvedor"
3. Clique em "Carregar sem compactacao"
4. Selecione a pasta chrome_extension

## Passo 2 - Testar

1. Abra uma pagina web
2. Clique no icone ADID
3. Escolha o modo de daltonismo
4. Clique em "Adaptar"
5. Verifique badges R/G ou B/Y na pagina

## Passo 3 - Resetar

- Clique em "Reset" para remover badges e restaurar estilos

## Observacoes

- O projeto funciona sem servidor local
- Em paginas internas do navegador, a extensao nao pode ser injetada
- Para file://, habilite "Allow access to file URLs"
